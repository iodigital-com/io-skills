# Observe behaviour in production

Decide which signals an on-call engineer needs when a feature goes live or user reports are hard to explain.

## Example prompt

> An export sometimes stays ‘Pending’. Which signals would tell us whether the job is still queued, processing has stopped or the status update is missing? Use one test export to trace the job from request to download.

## What do you get?

Targeted logs, metrics or traces that answer a specific operational question. For an alert, identify the signal that calls for action and how the on-call engineer can investigate further.
