# Review a code change

Review a diff before merging. Check that the change delivers the agreed behaviour, including when a user encounters an exception.

## Example prompt

> Review the diff that adds sorting to the task list. Select a task, then sort by due date. Does ‘Complete’ still act on the selected task? For any finding, identify the relevant line and the missing test.

## What do you get?

Findings point to the affected code and explain the conditions and impact of a defect. The review considers correctness, readability, architecture, security and performance.
