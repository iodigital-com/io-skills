# Record a technical decision

Write an architecture decision or update documentation when the reasoning behind a choice is getting lost or the explanation has drifted from the code.

## Example prompt

> Record why we keep the spec in a separate repository. Include the alternative of keeping it alongside the code and what reviewers now need to check.

## What do you get?

An architecture decision record (ADR) captures the context, decision, alternatives and consequences. When maintaining existing documentation, you get targeted corrections for confirmed differences from the implementation.
