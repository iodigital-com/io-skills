# Check accessibility

Audit an existing page against WCAG 2.2 AA when someone struggles with a keyboard, a screen reader or a zoomed-in view.

## Example prompt

> Compare Stad 400 and Route 800 using only the keyboard. Can you associate each price and battery life with the right light, add Route 800 and hear which model is in the basket using a screen reader?

## What do you get?

Findings identify the affected component, the relevant criterion and the impact on the user. The skill pairs automated checks with manual steps and repeats the affected checks after a fix.
