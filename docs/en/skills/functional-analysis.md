# Write a functional analysis

Explain agreed feature behaviour in the client's language. Use the optional functional analysis during a review or to update existing guidance after a spec change.

## Example prompt

> Use the agreed spec and prototype for leave requests. Explain what an employee sees after submitting a request and how their manager reviews that same request. Add a tested link to the right role and state beside each step.

## What do you get?

A readable document with concrete steps, visible outcomes and differences between roles. Where possible, a verified link opens the situation being described. Open questions and missing or unverified views are clearly identified.
