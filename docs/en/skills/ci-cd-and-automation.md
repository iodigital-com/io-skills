# Automate builds and tests

Set up the checks that run for every pull request or release when a team keeps repeating the same build and test steps.

## Example prompt

> Run our existing tests and build on each pull request. Make sure a teammate can find the first error from the failed pipeline step.

## What do you get?

A pipeline configuration with project commands, the order of checks and useful failure output. For releases, the skill can also cover preview deployments, rollout and rollback steps.
