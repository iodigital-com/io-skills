# Build an interface

Implement an agreed design using the project's components. Use this skill for responsive layouts, user interactions and different screen states.

## Example prompt

> Build the product comparison from our design spec. Keep price, lumens and battery life associated with the right bike light on a narrow screen. Make Route 800 selectable by mouse and keyboard.

## What do you get?

A working screen or component that uses the design system and adapts to the agreed widths. Checks cover relevant interactions, accessibility and the project's existing tests.
