# Independently challenge an assumption

Ask a second reviewer to examine a consequential technical assumption before the team builds on it.

## Example prompt

> We assume the selected light stays the same when the mobile comparison reorders its cards. Have an independent reviewer test that assumption by reversing the product order and selecting Route 800 again.

## What do you get?

An explicit claim, the relevant code or proposal and the conditions it must satisfy. A fresh review produces possible counterexamples, and the skill checks which findings hold up.
