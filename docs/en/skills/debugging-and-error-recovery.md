# Find the cause of a failure

Investigate unexpected behaviour when a test fails, a build breaks or a previously working action produces an error.

## Example prompt

> On mobile I choose the second light, Route 800, but the basket contains Stad 400. Reproduce this with an empty basket. Trace the product ID from the button to the basket line and identify where it first changes.

## What do you get?

A reproducible failure and an explanation you can check against the observations. After a targeted fix, repeat the original steps and check the surrounding behaviour.
