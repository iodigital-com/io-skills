# Plan a phased migration

Plan the transition when a new field, API or system needs to coexist with an older version.

## Example prompt

> Saved notifications currently identify the recipient by username. We want to store the stable user ID. Plan the transition while old and new app versions run side by side. How do we check that existing notifications still reach the right person?

## What do you get?

A staged migration covers existing consumers, ways to measure adoption and criteria for retiring the old path. Each step explains what to do if the transition runs into trouble.
