# Orient an agent in a project

Give an agent the project knowledge it needs for a task, for example when new sessions repeatedly pick the wrong module or an outdated spec.

## Example prompt

> A new agent session needs to make the email address editable on the profile page. Find the current spec, profile screen, code that saves the change and relevant test. Explain why each file matters and how to run the test locally.

## What do you get?

A focused selection of instructions, source files and commands for the task. Recurring conventions can go into project instructions with references to more detailed material.
