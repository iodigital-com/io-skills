# Protect access and data

Review how a feature handles input, grants access and stores data. Start with the information that needs protecting and who should be allowed to use it.

## Example prompt

> Review the checkout code for a test order. Check where the server validates the product ID and quantity and looks up the catalog price for Route 800. Identify any customer data that could end up in logs.

## What do you get?

An overview of sensitive data, access boundaries and concrete findings in the code. Each finding includes a suitable change and a way to verify the intended protection.
