# Find a performance bottleneck

Measure where time is spent when a screen starts slowly, a list stutters or a query slows down as a dataset grows.

## Example prompt

> Our activity list opens quickly with twenty rows, but with a thousand rows there’s a long delay before I can scroll. Measure both cases on the same phone, identify where the time goes and repeat the slow case after one targeted change.

## What do you get?

A baseline, an identified bottleneck and a targeted improvement. Repeating the measurement under the same conditions shows the effect on the specific action that was slow.
