# Break a spec into tasks

Turn a concrete spec into work that teammates can pick up. Use this when the sequence, size or dependencies of a change are still unclear.

## Example prompt

> Break our bike shop spec into small tasks. What agreement about product IDs and prices do we need before building the comparison page and basket in parallel? Give each task a check using Route 800.

## What do you get?

An ordered plan with an intended outcome and a way to verify each task. It identifies dependencies, checkpoints and work that can happen in parallel.
