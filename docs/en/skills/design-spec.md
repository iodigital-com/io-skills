# Sketch a screen layout

Use this skill to describe a screen layout with a text wireframe. The designer, developer and client can review the reading order and actions together before building a prototype.

## Example prompt

> Sketch a comparison screen for two products with attributes such as weight and dimensions. For example, one product weighs 800 g and the other weighs 1.2 kg. Show how a user can compare the values for each attribute and tell which value belongs to which product on both phone and desktop.

## What do you get?

A Markdown document with text wireframes, reading order and layout rules for different widths. It shows what moves, disappears or appears in each state or role, with specific checks for review.
