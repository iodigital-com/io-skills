# Test behaviour in the browser

Inspect a screen while it runs. With a connected Chrome DevTools MCP server, you can follow an interaction through the page, console and network traffic.

## Example prompt

> Open the task list at phone width and filter by ‘Open’. Reload the page. Check that the filter stays selected and only open tasks appear. If the results differ, record the URL and the network request.

## What do you get?

A repeatable sequence of actions with expected and observed results. Where relevant, a screenshot, network request or console message supplies evidence for the finding.
