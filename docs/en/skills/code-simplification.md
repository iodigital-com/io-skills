# Simplify working code

Make a working function easier to read when branches or duplication make its behaviour hard to predict.

## Example prompt

> The mobile and wide comparison views each determine which light to add to the basket in a different way. Simplify the code and verify the result for both models at both widths.

## What do you get?

A focused refactor with clearer names and decisions that are easier to follow. Existing checks or concrete input examples let you compare behaviour before and after the change.
