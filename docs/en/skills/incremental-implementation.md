# Build a feature incrementally

Work through an implementation plan in small changes that you can demonstrate and test across the relevant layers.

## Example prompt

> Our spec lets users save documents as favourites and open them later from a list. Build one working slice that lets me mark a document and still see it marked after a reload. Show me how to check that locally before adding the list.

## What do you get?

A working part of the feature with a concrete verification step. Later changes build on a checked starting point so the team can review or adjust after each step.
