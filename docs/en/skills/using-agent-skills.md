# Choose a skill for a task

Find a starting point in the library when you have a concrete task but are unsure which skill or sequence to use.

## Example prompt

> I have a brief and want to discuss the screen layout with the team. Which skill should I start with, and what input will the next skill need?

## What do you get?

A selection from the available skills with a reason for each choice. When several steps are needed, you get a sequence in which the output of one skill helps you start the next.
