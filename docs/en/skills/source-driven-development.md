# Ground a technical choice in sources

Check how to use a library or framework against the official documentation for the version in the project.

## Example prompt

> Check the official documentation for our installed router to see how a comparison link preserves both product IDs across a reload. Name the relevant API and apply it to Stad 400 and Route 800.

## What do you get?

An approach with references to official sources and an example applied to the project. When the version changes, you can trace the decision back to the documented behaviour it relies on.
