# Design an API contract

Define how parts of an application exchange data when several teams or screens will rely on the same interface.

## Example prompt

> Design the contract for adding one Route 800 to the basket. Show the product ID and quantity in the input, the price in the response and what the shop receives for an unknown product ID.

## What do you get?

A contract with example requests and responses, agreed data types and identifiable error cases. It also identifies changes that would affect existing consumers of the interface.
