# Organise Git changes

Structure branches, commits and versions when several changes are ready for review or teams are working on a feature in parallel.

## Example prompt

> The form change and a copy correction are in the same working directory. How can I split them into two independently reviewable commits?

## What do you get?

A breakdown into coherent changes with an appropriate commit message and checks for each step. For parallel work, the skill can also set up a separate worktree for each task.
