# Kwaliteitsafspraken vastleggen

Spreek meetbare eisen af wanneer woorden als snel of toegankelijk in een project voor verschillende dingen kunnen staan.

## Voorbeeldvraag

> We willen dat de vergelijking van de fietslichten snel bruikbaar wordt op een telefoon. Kies samen met mij een meetbare grens, een representatief testtoestel en een herhaalbare controle voor wijzigingen aan dit scherm.

## Wat krijg je?

Een `CONSTRAINTS.md` met afgesproken grenzen, hoe je ze controleert en hoe je uitzonderingen vastlegt. Een controle op de diff maakt bijvoorbeeld overgeslagen tests en verlaagde drempels zichtbaar.
