# Git-wijzigingen overzichtelijk maken

Breng structuur aan in branches, commits en versies wanneer meerdere wijzigingen klaarstaan voor review of teams tegelijk aan een feature werken.

## Voorbeeldvraag

> De aanpassing aan het formulier en een tekstcorrectie zitten in dezelfde werkmap. Hoe splits ik ze op in twee onafhankelijk te beoordelen commits?

## Wat krijg je?

Een indeling in samenhangende wijzigingen, met een passende commitboodschap en controles per stap. Bij parallel werk kan de skill ook een aparte worktree per taak inrichten.
