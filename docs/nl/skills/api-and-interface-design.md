# Een API-contract ontwerpen

Leg vast hoe delen van een toepassing gegevens uitwisselen wanneer meerdere teams of schermen op dezelfde interface gaan bouwen.

## Voorbeeldvraag

> Ontwerp het contract om één Route 800 aan de mand toe te voegen. Toon de product-ID en het aantal in de invoer, de prijs in het antwoord en wat de webshop terugkrijgt bij een onbekende product-ID.

## Wat krijg je?

Een contract met voorbeeldverzoeken en antwoorden, afgesproken datatypes en herkenbare foutgevallen. Je ziet ook welke wijzigingen bestaande gebruikers van de interface zouden raken.
