# Een passende skill kiezen

Zoek een ingang in de bibliotheek wanneer je een concrete taak hebt en nog niet weet welke skill of volgorde daarbij past.

## Voorbeeldvraag

> Ik heb een briefing en wil de schermindeling met het team bespreken. Met welke skill begin ik en welke informatie heeft de volgende skill nodig?

## Wat krijg je?

Een keuze uit de beschikbare skills met de reden waarom elke skill bij de opdracht past. Bij meerdere stappen krijg je een volgorde waarin het resultaat van de ene skill de volgende op weg helpt.
