# Bouwen en testen automatiseren

Richt de controles in die bij elke pull request of release horen wanneer een team steeds dezelfde bouw- en teststappen uitvoert.

## Voorbeeldvraag

> Laat onze pipeline bij een pull request de bestaande tests en build uitvoeren. Zorg dat een collega de eerste fout vanuit de mislukte stap kan vinden.

## Wat krijg je?

Een pipelineconfiguratie met de projectcommando’s, de volgorde van controles en bruikbare foutuitvoer. Voor releases kun je ook de stappen voor een preview, uitrol of terugdraaiing laten uitwerken.
