# Een technische keuze onderbouwen

Controleer het gebruik van een bibliotheek of framework aan de hand van officiële documentatie die past bij de versie in het project.

## Voorbeeldvraag

> Na herladen verliest onze zoekpagina het gekozen filter. Zoek de routerversie op in het project en controleer in de officiële documentatie hoe die versie queryparameters ondersteunt. Toon hoe we het filter ‘Open’ kunnen bewaren in een deelbare URL en link naar de bron.

## Wat krijg je?

Een aanpak met verwijzingen naar de officiële bronnen en een toepassing in de context van het project. Je kunt bij een volgende versie nagaan op welke gedocumenteerde afspraak de keuze steunt.
