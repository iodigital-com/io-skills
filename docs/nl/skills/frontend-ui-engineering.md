# Een scherm bouwen

Werk een afgesproken ontwerp uit in de componenten van het project. Gebruik de skill voor responsieve schermen, gebruikersinteractie en verschillende schermtoestanden.

## Voorbeeldvraag

> Bouw de voorkeurenpagina met onze bestaande formuliercomponenten. Iemand kan e-mailmeldingen aanzetten en de keuze opslaan. Houd de opslaanknop bereikbaar op telefoonbreedte en laat bij een mislukte opslag de gemaakte keuze staan zodat de gebruiker opnieuw kan proberen.

## Wat krijg je?

Een werkend scherm of component dat het designsysteem gebruikt en zich aanpast aan de afgesproken schermbreedtes. De controles sluiten aan bij de interacties, toegankelijkheid en bestaande projecttests.
