# Werkende code vereenvoudigen

Maak een bestaande functie beter leesbaar als vertakkingen of herhaling het moeilijk maken om haar gedrag te voorspellen.

## Voorbeeldvraag

> Het aanmaakformulier en het bewerkformulier valideren een einddatum elk op hun eigen manier. Leg voor beide vast wat er gebeurt bij een lege datum, een eerdere einddatum en gelijke datums. Vereenvoudig de dubbele logica en controleer die gevallen opnieuw.

## Wat krijg je?

Een gerichte refactor met herkenbare namen en een beter te volgen beslisstructuur. Met de bestaande controles of concrete invoervoorbeelden vergelijk je het gedrag vóór en na de wijziging.
