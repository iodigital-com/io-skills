# Een codewijziging beoordelen

Bekijk een diff vóór het samenvoegen. Controleer of de wijziging het afgesproken gedrag levert, ook als een gebruiker een uitzondering tegenkomt.

## Voorbeeldvraag

> Review de wijziging aan de mobiele vergelijkingskaart. Volg de gekozen product-ID tot in de mand. Blijft de keuze voor Route 800 correct als de producten in een andere volgorde staan? Wijs de relevante test aan.

## Wat krijg je?

Bevindingen verwijzen naar de betrokken code en beschrijven de omstandigheden en het effect van een fout. De review weegt onder meer correctheid, leesbaarheid, architectuur, beveiliging en prestaties mee.
