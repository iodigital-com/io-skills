# Een feature stap voor stap bouwen

Werk een implementatieplan uit in kleine wijzigingen die je elk door de relevante lagen heen kunt demonstreren en testen.

## Voorbeeldvraag

> Bouw eerst de kleinste stap waarin ik Stad 400 en Route 800 kan vergelijken en de gekozen Route 800 in de mand zie. Laat me die stap lokaal testen voordat je de testbestelling uitwerkt.

## Wat krijg je?

Een werkend deel van de feature met een concrete verificatiestap. Volgende wijzigingen bouwen voort op een gecontroleerd vertrekpunt, zodat het team per stap kan reviewen of bijsturen.
