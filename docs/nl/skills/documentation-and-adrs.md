# Een technische beslissing vastleggen

Schrijf een architectuurbesluit of werk documentatie bij wanneer de reden voor een keuze dreigt te verdwijnen of de uitleg afwijkt van de code.

## Voorbeeldvraag

> Leg vast waarom we de spec in een aparte repository bewaren. Beschrijf ook de afweging om haar naast de code te zetten en wat reviewers nu moeten controleren.

## Wat krijg je?

Een beslisdocument (ADR) beschrijft de context, de gekozen oplossing, overwogen alternatieven en gevolgen. Bij onderhoud van bestaande documentatie krijg je gerichte correcties voor de vastgestelde verschillen met de implementatie.
