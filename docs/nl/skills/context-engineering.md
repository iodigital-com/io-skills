# Een agent wegwijs maken

Geef een agent de projectkennis die nodig is voor een taak, bijvoorbeeld wanneer een nieuwe sessie telkens de verkeerde module of oude spec kiest.

## Voorbeeldvraag

> We voegen een vergelijker toe aan onze bestaande fietswebshop. Waar vind ik de categorie-indeling, de productkenmerken, de huidige bestelknop en de test voor één artikel in de mand? Geef een nieuwe sessie de geldende spec en alleen de bestanden die ze hiervoor nodig heeft.

## Wat krijg je?

Een gerichte selectie van instructies, bronbestanden en commando’s voor de taak. Terugkerende afspraken kunnen in de projectinstructies, met verwijzingen naar uitgebreidere informatie.
