# Een wijziging gefaseerd migreren

Plan de overgang wanneer een nieuw veld, een nieuwe API of een nieuw systeem tijdelijk naast een oude versie moet werken.

## Voorbeeldvraag

> Onze oudere mandregels bewaren de naam van het fietslicht. We willen voortaan de vaste product-ID bewaren. Stel een migratie voor en laat met een oude mand met Route 800 zien hoe de overgang werkt.

## Wat krijg je?

Een migratie in stappen met ruimte voor bestaande gebruikers, meetpunten voor de overstap en een onderbouwd moment om de oude route te verwijderen. Per stap zie je hoe je bij problemen terug kunt.
